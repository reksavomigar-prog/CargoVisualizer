# CargoVisualizer

CLI-утилита на C# (.NET) для анализа и визуализации транзитивного графа зависимостей пакетов экосистемы **Rust (Cargo)** без использования менеджера пакетов `cargo` и сторонних библиотек.

## Описание функций и настроек

На текущем этапе реализованы:
1. **Чтение и валидация конфигурации (Этап 1):** разбор CSV-файла настроек с проверкой всех 6 обязательных параметров.
2. **Сбор метаданных реестра Cargo (Этап 2):** взаимодействие по HTTP с REST API реестра пакетов (`crates.io`) и разбор JSON-метаданных версий и зависимостей.
3. **Построение транзитивного графа зависимостей (Этап 3):**
   * поуровневый обход графа алгоритмом **поиска в ширину (BFS) с рекурсией**;
   * ограничение глубины анализа параметром `MaxDepth`;
   * защита от циклических и ромбовидных зависимостей при обходе;
   * поддержка локального **режима тестирования** (`IsTestMode=true`) с чтением графа из файла, где пакеты заданы заглавными латинскими буквами (`A`, `B`, `C` и т.д.).

### Параметры конфигурационного файла (CSV)

Конфигурация передается в виде построчного CSV-файла формата `Ключ,Значение` (по умолчанию используется `config.csv` в текущей директории):

| Параметр | Тип | Описание | Правила валидации |
| :--- | :--- | :--- | :--- |
| `Name` | `string` | Имя корневого анализируемого пакета | Непустая строка (в тестовом режиме — заглавные латинские буквы `A–Z`) |
| `Url` | `string` | URL-адрес реестра Cargo или путь к файлу тестового графа | Корректный HTTP/HTTPS URL при `IsTestMode=false`; путь к существующему файлу при `IsTestMode=true` |
| `IsTestMode` | `bool` | Режим работы с локальным тестовым репозиторием | `true` или `false` |
| `Version` | `string` | Конкретная версия корневого анализируемого пакета | Непустая строка |
| `OutputFileName` | `string` | Имя выходного файла для изображения графа | Непустая строка без запрещенных символов ФС |
| `MaxDepth` | `int` | Максимальная глубина обхода графа зависимостей | Целое неотрицательное число (`>= 0`) |
