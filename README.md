# CargoVisualizer

CLI-инструмент для анализа и визуализации графа зависимостей пакетов экосистемы Rust (Cargo) без использования сторонних менеджеров пакетов и библиотек получения зависимостей.

## Описание функций и настроек

На текущем этапе реализовано чтение, синтаксический разбор и строгая валидация параметров приложения из конфигурационного файла формата **CSV** (построчный формат `Ключ,Значение`).

### Настраиваемые параметры конфигурации

| Параметр | Тип | Описание | Правила валидации |
| :--- | :--- | :--- | :--- |
| `Name` | `string` | Имя анализируемого пакета Rust | Обязательный параметр, непустая строка |
| `Url` | `string` | URL-адрес удаленного репозитория или путь к файлу тестового репозитория | При `IsTestMode=false` — корректный `http`/`https` URL; при `IsTestMode=true` — непустой путь к файлу |
| `IsTestMode` | `bool` | Режим работы с локальным тестовым репозиторием | Допустимы только значения `true` или `false` |
| `Version` | `string` | Анализируемая версия пакета | Обязательный параметр, непустая строка |
| `OutputFileName` | `string` | Имя генерируемого файла с изображением графа | Непустая строка без запрещенных символов файловой системы |
| `MaxDepth` | `int` | Максимальная глубина обхода графа зависимостей | Целое неотрицательное число (`>= 0`) |
