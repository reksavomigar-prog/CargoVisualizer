# CargoVisualizer

CLI-утилита на C# (.NET) для анализа и визуализации графа зависимостей пакетов экосистемы **Rust (Cargo)** без использования менеджера пакетов `cargo` и сторонних библиотек.

## Функциональность и настройки

На текущем этапе реализованы:
1. **Чтение и валидация конфигурации (Этап 1):** разбор CSV-файла настроек с проверкой всех 6 обязательных параметров.
2. **Сбор данных о прямых зависимостях (Этап 2):** обращение по HTTP к REST API удаленного реестра пакетов Cargo (`crates.io`), разбор JSON-метаданных и вывод списка прямых зависимостей указанной версии пакета.

### Параметры конфигурационного файла (CSV)

Конфигурация передается в виде построчного CSV-файла формата `Ключ,Значение` (по умолчанию используется `config.csv` в текущей директории):

| Параметр | Тип | Описание | Правила валидации |
| :--- | :--- | :--- | :--- |
| `Name` | `string` | Имя анализируемого пакета Rust | Непустая строка |
| `Url` | `string` | URL-адрес реестра Cargo или путь к тестовому файлу | Корректный HTTP/HTTPS URL при `IsTestMode=false`; непустой путь при `IsTestMode=true` |
| `IsTestMode` | `bool` | Режим работы с локальным тестовым репозиторием | `true` или `false` |
| `Version` | `string` | Конкретная версия анализируемого пакета | Непустая строка |
| `OutputFileName` | `string` | Имя выходного файла для изображения графа | Непустая строка без запрещенных символов ФС |
| `MaxDepth` | `int` | Максимальная глубина анализа зависимостей | Целое неотрицательное число (`>= 0`) |
